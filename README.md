# Хаммам по-турецки — Timur Turkish

Лексика темы «Хаммам»: анатомия хаммама, три зала, суффикс -lık, банная сумка, ритуал из шести шагов,
диалог с банщиком, пять идиом, квиз. История в духе коротких тредов: рубленые фразы, диалоги через тире,
развязка отдельной строкой. В конце — переход на платформу **Alterna Timur A0 → C1**.

Дизайн: лендинг Behance «International Forum in Batumi» (светлый фон, тонкие заголовки капсом, рукописные
акценты, золотые кнопки, карточки 01–06, тарифы, чат-пузыри, голубая витрина с ноутбуком и телефоном,
«Спасибо всем») плюс приёмы из «UX/UI Design for Metropolitan Museum of Art» (нумерация разделов (09),
сторис и профиль в стиле соцсетей). Иллюстрации — свой SVG: хаммам с куполами, воздушный шар, пальмы,
интерьер с «глазами слона».

Сборка и озвучка (голос Yelda, синтез macOS):

```bash
python3 tools/build.py
python3 tools/gen_audio.py
python3 tools/build.py
```

Обложки (`assets/media/cover*.{jpg,webp}`) рендерятся из `tools/cover.html` через headless Chrome.
